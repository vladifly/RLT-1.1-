So, how do you play the game? As you may have already seen, the .exe file is located in the project's root directory. You're supposed to download the compressed archive by clicking the green "Code"  and "Download ZIP" buttons. Then, unpack the archive, open the project folder and move the .exe file to your desktop. 
Open it. The app will launch.

For convenience, you can drag the exe file to your desktop.
